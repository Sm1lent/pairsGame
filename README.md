# Игра "найди пару"
Цель игры - найти пару каждой карте.

## Реализация
Игра написана на TS с полной инкапсуляцией. Она реализована классами и при желании может быть вставлена в любой проект, ничего не потеряв (при достаточном размере родительского элемента). 

## Режимы игры
Можно выбрать одну из четырёх сложностей - с возрастающим количеством карт и временем на их поиск - либо задать количество карт и времени вручную. Неверно введённые данные будут скорректированы.

## Визуализация
Интерфейс предназначен для использования на стационарных устройствах (с шириной экрана от 1200рх).
